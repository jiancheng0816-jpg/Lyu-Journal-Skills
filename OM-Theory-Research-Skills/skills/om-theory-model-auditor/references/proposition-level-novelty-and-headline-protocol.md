# Proposition-Level Novelty and Headline Protocol

Use this protocol after mathematical correctness has been established and before a paper is reconstructed.

## 1. Build the proposition inventory

For every lemma, proposition, theorem, corollary, major numerical claim, and managerial conclusion, record:

- exact statement and conditions;
- proof status;
- economic mechanism;
- direct endogenous consequence;
- benchmark/predecessor result;
- closest prior analogue;
- downstream role in later results;
- current manuscript role.

Do not infer importance from original numbering.

## 2. Run the closest-result tests

### Equivalence test
Ask whether the result becomes a known result after renaming variables, normalizing parameters, taking a special case, or imposing/removing a slack constraint.

### Nested-recovery test
If the present model claims to generalize a prior model, recover that model and its result under the stated restriction.

### Mechanism-isomorphism test
Different equations may encode the same causal chain. Identify the binding constraint, payoff difference, or strategic response that actually drives the result.

### Shape-is-not-novelty test
An interior optimum, threshold, U-shape, inverted-U, sign reversal, or regime partition is not a contribution unless the mechanism producing it is genuinely distinct.

### Composition test
If the result only balances one known increasing force and one known decreasing force, treat the balance formula as a characterization unless the interaction creates a new behavior, endogenous decision, or design implication.

### Conditional-versus-aggregate test
Keep separate:
- conditional/postdecision behavior;
- entry/funding/participation probability;
- aggregate realized outcome.

A behavioral claim requires an endogenous behavioral object.

## 3. Assign novelty-sensitive labels

Use one of:

- PRIOR RESULT / SAME MECHANISM
- SPECIAL CASE OR REPARAMETERIZATION
- COMBINATION OF KNOWN CHANNELS
- NEW BOUNDARY / REGIME
- NEW EQUILIBRIUM CONSEQUENCE
- NEW MECHANISM
- NEW DESIGN IMPLICATION
- NOVELTY UNRESOLVED

If literature coverage is incomplete, send the unresolved item to `om-literature-positioning` rather than overstating novelty.

## 4. Identify headline results

A headline result must satisfy:

- correctness;
- proposition-level novelty;
- non-obvious mechanism;
- decision or performance significance;
- centrality to the paper;
- mechanism robustness;
- narrative independence.

Prefer 2–4 headline results.

## 5. Audit result lineage

For each candidate headline, write:

`new primitive -> new constraint/strategic response -> new mechanism -> new endogenous consequence`.

If any link is absent, downgrade the claim.

Use the provenance labels:

- Inherited
- Adapted
- Interaction
- New mechanism
- New consequence

## 6. Test whether the main model is the right model

Promote a later model when it is the first place where the paper's claimed mechanism directly exists.

Demote the current main model when it:
- is kept mainly for closed form;
- suppresses the key behavior;
- is close to prior literature;
- only produces the headline shape indirectly through selection or entry;
- is a useful special case rather than the conceptual core.

The simplest mechanism-faithful model should be the main model.

## 7. Produce the promotion/demotion matrix

Use:

| Result | Math status | Prior overlap | Mechanism | Current role | Recommended role | Reason |
|---|---|---|---|---|---|---|

Recommended roles:
Headline; Core mechanism; Equilibrium consequence; Benchmark; Extension; Robustness; Appendix; Merge/Delete.

## 8. Handoff to the builder

Provide:

- one-sentence core mechanism;
- verified headline sequence;
- main-model choice;
- benchmark jobs;
- design/extension jobs;
- items that must move to appendix;
- claims that must be removed or weakened;
- any novelty issue still requiring literature verification.
